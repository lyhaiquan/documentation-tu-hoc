# Danh mục sách mà giáo án cần

Repo này **có kèm bản sao các sách PDF** mà giáo án dùng (để dùng cá nhân; repo để PRIVATE, đừng công khai vì bản quyền). Giáo án `giao-an-theo-mon.html` trỏ tới các PDF theo đường dẫn tương đối ở bảng dưới.
Clone repo về là link mở được ngay. Nếu bạn chỉ có HTML: đặt PDF đúng đường dẫn này **cạnh** file HTML. Số trang là số trang PDF (khớp thanh trang của trình xem). Nếu file của bạn là bản khác (khác số trang), chạy lại `_src-giao-an/mktoc.py` rồi `build.py` để sinh lại trang.
