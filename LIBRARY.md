# Danh mục sách mà giáo án cần

Repo này **không chứa sách** (bản quyền và dung lượng). Giáo án `giao-an-theo-mon.html` trỏ tới các PDF theo đường dẫn tương đối ở bảng dưới.
Muốn link mở được: đặt PDF đúng đường dẫn này **cạnh** file HTML (cùng thư mục gốc với `giao-an-theo-mon.html`). Số trang là số trang PDF (khớp thanh trang của trình xem). Nếu file của bạn là bản khác (khác số trang), chạy lại `_src-giao-an/mktoc.py` rồi `build.py` để sinh lại trang.
